
# Myntra Clone 👗

## About the Project
Myntra Clone is a fashion shopping website inspired by Myntra.
It is developed as a college project using HTML, CSS and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Features
- Attractive homepage
- Navigation bar
- Product search functionality
- Category filtering
- Product sorting
- Add to Bag functionality
- Wishlist functionality
- Cart quantity management
- Total price calculation
- Responsive design

## Project Structure
- index.html - Website structure
- style.css - Website styling
- script.js - Website functionality
- images - Product images

## How to Run
1. Download or clone this repository.
2. Open the Myntra-Clone folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.
